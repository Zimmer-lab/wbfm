# Paper datasets

This page documents the datasets used in the paper:

> An intrinsic neuronal manifold underlies brain-wide hierarchical organization of behavior in *C. elegans* ([bioRxiv 2025.03.09.642241](https://www.biorxiv.org/content/10.1101/2025.03.09.642241v1))

It is meant as a high-level guide to the shared data folders plus the per-neuron Excel summaries in this repo.

For how to load these datasets in code, see `wbfm/utils/general/utils_hardcoded.py` (`load_paper_datasets`, `load_all_paper_datasets`, `default_raw_data_config`) and the reproduction notebooks in `wbfm/notebooks/paper/`.

## Overview

All freely moving recordings use the same basic preparation: strain ZIM2165 (GCaMP + mScarlet reference, unless noted), spacer + 2% agar, ~8 min volumetric recordings (nominally 22 z-planes, 1.5 µm step; see `default_raw_data_config()`). The pipeline tracks neurons on the red (mScarlet) reference channel and extracts activity from the green (GCaMP) channel. See [NWB file format](nwb_format.md) and [Data folder organization](data_folder_organization.md).

| Dataset group | What it is | N (paper analysis) | Strain / condition |
|---|---|---|---|
| Freely moving GCaMP | Main wild-type freely moving set. Pools the 2022 batches (`2022-11-23`, `2022-11-27`, `2022-11-30`, `2022-12-05`, `2022-12-10` spacer_7b_2per_agar) plus later freely moving WT (`brenner/.../freely_moving_wt`, `IM_to_FM_freely_moving`) | 36 | ZIM2165, no stimulus |
| Freely moving GFP | Activity-independent motion-artifact control | 8 | ZIM2319 (GFP in place of GCaMP), 10.12.2022 |
| Freely moving mutant | O2-sensing-deficient control | 7 | `gcy-9; gcy-31; gcy-35` triple mutant, freely moving, no gas stimulus |
| Immobilized GCaMP (no O2) | Immobilized comparison set | 10 | ZIM2165, no O2 stimulus |
| Immobilized GCaMP + O2 stimulus | Immobilized with O2 up/downshifts | 10 | ZIM2165, O2 stimulus |
| Immobilized mutant + O2 | Same O2 protocol on mutant background | 4 | `gcy-9; gcy-31; gcy-35`, O2 stimulus |
| Immobilized HisCl + O2 | Alternate immobilization (HisCl) with O2 stimulus | 4 | ZIM2165 background, HisCl, O2 stimulus |

Counts above are the "Number of Datasets" maxima from the Excel summaries (per-neuron counts are lower when a neuron was not confidently identified in every dataset)

Only immobilized recordings have a gas stimulus. Freely moving recordings (WT, GFP, mutant) are just freely moving.

## Per-neuron Excel summaries

These live alongside the paper notebooks and are the authoritative source for "which neuron was found in how many datasets / events":

- `wbfm/notebooks/paper/supplement/ids/ids_per_dataset_type.xlsx` — rows = dataset types, columns = confidently identified neurons, values = number of datasets in which that neuron was identified. Last column (`Number of Datasets`) = total datasets of that type. Generated by `wbfm/notebooks/paper/supplement/fig_S2_ided_neurons_table.py`.
- `wbfm/notebooks/paper/supplement/ids/events_per_id.xlsx` — rows = event types (`raw_rev`, `raw_fwd`, `self_collision`, `residual`, `residual_rectified_fwd/rev`, `immob-*`, `mutant-*`, `GFP-*`, plus `num_datasets_*` rows), columns = neurons (individual and left-right-pooled names), values = event counts. Also has `Description` and `Figure panel references` columns. Generated by `wbfm/notebooks/paper/fig_4_O2_neurons.py`. Row meanings are defined in code in `excel_event_full_description()` (`wbfm/utils/general/utils_hardcoded.py`).
- `wbfm/notebooks/paper/intro/intrinsic_categories.xlsx` (also `revisions/fig3/intrinsic_categories*.xlsx`) — per-neuron manifold classification (`Intrinsic`, `Intrinsic (modulated)`, `Freely moving only`, `Immobilized only`, `Encoding switches`, `No manifold`). Logic is in `intrinsic_definition()` (`wbfm/utils/general/utils_hardcoded.py`).
- `wbfm/notebooks/paper/revisions/ids/events_per_id.xlsx` — newer working copy of the events table with updated figure references; prefer the `supplement/` version when matching the published figures.

Neuron lists used throughout: `neurons_with_confident_ids()` and `neurons_with_less_confident_ids()` in `wbfm/utils/general/utils_hardcoded.py`; functional groups in `neuron_groups()`.

## FAQ (from user questions)

### What does "FM" mean? Are FM files shorter / a different protocol?

FM means freely moving. All FM recordings (including "FM"-tagged ones) are the same genotype and in principle the same conditions/protocol/rig; some were taken by different people, which explains batch naming differences. They should all be roughly the same size/length.

### Do "again" / "again2" mean the same animal was recorded twice?

No. Those are ad-hoc notes by the experimenters. No animal appears in more than one dataset.

### In the ZIM2165 set, the same worm number appears on several dates (e.g. worm1 on 28.11, 30.11, 10.12). Same animal?

No. Numbering restarts each day. Every recording is a different animal.

### Were the 2022 and 2023/24 batches acquired the same way? Can they be pooled?

In principle yes: same microscope, volumetric protocol, and processing pipeline. The paper pools them (23 from 2022 + later WT to reach 36 FM GCaMP datasets). Caveat: pooling is nontrivial because of bleaching and inter-individual differences. The classic preprocessing used for the immobilized datasets (e.g. Liana's steps) makes assumptions that do not transfer to freely moving data.

### GFP folder (ZIM2319, 8 worms, 10.12.2022): motion-artefact control? Matched sessions?

Yes: GFP in place of GCaMP, i.e. the activity-independent control for motion artifacts. It was recorded on the same day as some ZIM2165 worms, but there are no matched sessions — treat it as an unmatched control group.

### Mutant folder (gcy-9; gcy-31; gcy-35, 5 worms, 30.01.2024): were the 2 WT worms that afternoon same-day controls? Different O2/CO2?

Controls were recorded mostly on the same days mutants were recorded, but they were not exactly matched sessions. Otherwise conditions are the same. Nothing was different about O2/CO2: freely moving animals get no gas stimulus at all (only immobilized experiments have an O2 stimulus).
